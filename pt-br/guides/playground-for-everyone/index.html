WordPress Playground para Todos

O WordPress Playground permite que você execute o WordPress instantaneamente — sem servidor, sem configuração, sem riscos. Ele funciona no seu navegador em playground.wordpress.net, e desenvolvedores também podem usá-lo via CLI, Node.js, ou incorporado em seus próprios aplicativos. Mas você não precisa ser técnico para se beneficiar dele.

Assista a esta visão geral rápida:

Pense Nisso Como um Simulador de Carro​

Um simulador de carro oferece um volante, pedais e ruas virtuais. Pratique dirigir, bata em cones, cometa erros — nada de ruim acontece. Nenhum carro real é danificado. Quer tentar novamente? Basta reiniciar.

O WordPress Playground funciona da mesma forma. Ele oferece um site WordPress completo para você experimentar, mas nada do que você faz afeta nenhum site real. Faça alterações, quebre coisas, aprenda com os erros — e depois comece do zero quando quiser.

O Que Você Pode Fazer com o Playground?​

Quando você visita playground.wordpress.net, você obtém um site WordPress rodando inteiramente no seu navegador. Você pode:

  • Instalar plugins e temas
  • Editar páginas e criar conteúdo
  • Alterar versões do WordPress e PHP
  • Explorar recursos que você nunca experimentou antes

Por padrão, o WordPress Playground carrega uma página inicial para apresentar alguns dos recursos do Playground e onde você pode aprender mais sobre ele. Mas você também pode carregar uma versão vanilla do WordPress sem a página inicial. No painel de Inicialização do Playground, uma opção é carregar uma versão vanilla do WordPress.

  1. Abra o Painel de Inicialização do WordPress
  1. Selecione para carregar uma versão Vanilla do WordPress

Se Você Está Aprendendo WordPress​

Você é novo no WordPress ou está tentando entender recursos como o Editor do Site ou os novos recursos da última versão do WordPress? O Playground é o seu espaço de prática perfeito.

Explore Como as Páginas São Construídas​

O Playground faz login como administrador, então você pode editar qualquer página. Clique em Editar para editar posts e Editar Site para atualizar o layout do site na barra de ferramentas superior para abrir o editor.

Quer entender como um layout de página foi criado? Abra a Visualização em Lista (o ícone de três linhas horizontais) para ver cada bloco que compõe a página.

Você pode inspecionar colunas, títulos, imagens e botões — e ver exatamente como eles estão organizados. Esta é uma forma poderosa de aprender pelo exemplo.

Explore a Biblioteca de Blueprints​

No painel de Inicialização do WordPress Playground, você terá acesso à Biblioteca de Blueprints, um conjunto de mais de 40 blueprints para inspirá-lo e experimentar diferentes tipos de sites com o WordPress Playground. Galeria de Arte, E-commerce e Portfólio Web são alguns dos exemplos.

  1. Abra a galeria de Blueprints no Painel de Inicialização do Playground
  1. Navegue e selecione o Blueprint para iniciar no WordPress Playground

Experimente Novos Recursos com Segurança​

Quando a equipe do WordPress lança novos recursos, você pode testá-los no Playground antes que afetem seu site real. Selecione qualquer versão do WordPress no painel de configurações para explorar o que há de novo — ou o que está por vir.

Se Você Possui um Site WordPress​

Manter um site ao vivo significa que cada mudança arrisca quebrar algo. O Playground permite que você teste antes de se comprometer.

Teste Plugins Antes de Instalar​

Curioso sobre um novo plugin de SEO? Quer comparar duas opções de formulário de contato? Instale-os no Playground primeiro:

  1. Abra playground.wordpress.net
  2. Vá para Plugins → Adicionar Novo
  3. Pesquise e instale qualquer plugin
  4. Teste-o completamente

Seu site real permanece intocado enquanto você avalia se o plugin atende às suas necessidades.

Visualize Mudanças de Tema​

Pensando em trocar de tema? Teste seu novo tema no Playground para ver como ele lida com seu conteúdo — sem perturbar seus visitantes.

Compare Opções Lado a Lado​

Abra várias abas do navegador com diferentes configurações do Playground. Compare o plugin A versus o plugin B, ou veja como seu conteúdo fica em diferentes temas. Tome decisões informadas antes de mexer no seu site de produção.

Seu Site Real Permanece Seguro

Cada Playground roda independentemente no seu navegador. Nada sincroniza com nenhum servidor externo, e nada afeta sua instalação WordPress ao vivo.

Se Você Usa WordPress Diariamente​

Mesmo usuários experientes de WordPress se beneficiam de um ambiente de testes seguro.

Faça Experimentos de Design​

Quer experimentar um tamanho de fonte diferente? Ajustar espaçamento? Mudar cores? Carregue um Playground com o mesmo tema que você está usando em produção e edite livremente:

  1. Abra qualquer página no editor
  2. Selecione um bloco e modifique suas configurações
  3. Veja os resultados imediatamente

Se você gostar do que vê, recrie essas mudanças no seu site real. Se não, apenas feche a aba — nenhuma limpeza necessária.

Sim, Você Pode Salvar Seu Trabalho​

O Playground não precisa ser temporário. Você pode salvar seu progresso e voltar a ele mais tarde.

Salve no Seu Navegador​

  1. Agora o WordPress Playground informa se sua instância do Playground não está salva no canto superior direito
  2. Clique em Salvar (botão amarelo)
  3. Defina o nome da sua instância

O Playground gera um link único para seu site salvo. Adicione aos favoritos, e você pode retornar exatamente de onde parou.

Baixe como um Arquivo ZIP​

Precisa mover seu trabalho para outro lugar? Escolha Baixar como .zip para exportar todo o seu Playground — incluindo plugins, temas e conteúdo. Você pode restaurá-lo mais tarde ou até hospedá-lo em um servidor real.

Guarde Seu Link do Playground

Quando você salvar no navegador, copie a URL única que ele gera. Esse link é o seu caminho de volta ao seu trabalho salvo.
