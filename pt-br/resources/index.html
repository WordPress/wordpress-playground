Links e Recursos

dica

Há um conjunto de redirecionamentos disponíveis para facilitar o acesso a algumas das ferramentas relacionadas ao Playground:

  • https://playground.wordpress.net/ → Instância do Playground
  • https://playground.wordpress.net/docs → Documentação do Playground
  • https://playground.wordpress.net/builder → Construtor de Blueprints do Playground
  • https://playground.wordpress.net/wordpress → Visualizador de PR do Playground para WordPress
  • https://playground.wordpress.net/gutenberg → Visualizador de PR do Playground para Gutenberg
  • https://playground.wordpress.net/proxy → Serviço Proxy do Playground (veja URLReference para mais informações)
