Documentação do WordPress Playground

Está procurando a versão web do WordPress Playground?

A página oficial do WordPress Playground está disponível em wordpress.org/playground/. Esta página abriga a documentação do WordPress Playground.

👋 Olá! Bem vindo a documentação oficial do WordPress Playground.

WordPress Playground é uma ferramenta online onde podes testar e aprender mais sobre o WordPress. Nesta página(Documentação) irá encontrar todas as informações necessárias para começar a trabalhar com o Playground.

A documentação do WordPress Playground está dividida em quatro hubs(subsites):

  • 👉 Documentação (você está aqui) – Introdução a WordPress Playground, guia inicial e ponto de entrada para a documentação do WordPress Playuground.
  • Blueprints – Blueprints são arquivos JSON que permitem configurar e definir o estado de novas instâncias do WordPress Playground. Saiba mais o que é possível com Blueprints na sessão dedicada.
  • Desenvolvedores – WordPress Playground é uma ferramenta poderosa para desenvolvedores onde podemos criar ambiente de desenvolvimento e testes. Descubra mais o que podes fazer com o WordPress playground na sessão dedica a desenvolvedores.
  • Referência da API – Referência de toda a API pública do WordPress Playground.

Navegando neste hub de documentação​

Este hub de documentação foca-se em ajudá-lo a começar a trabalhar com o WordPress Playground e está organizado nas seguintes seções:

  • Guia de início rápido: Para aqueles que querem começar com o WordPress Playground, neste guia você aprenderá como colocar rapidamente no ar um site WordPress para testar um bloco, um tema ou um plugin ou para testar uma versão específica do WordPress ou PHP.
  • A instância do WP Playground: Aprenda os detalhes da instância pública do WP Playground que está disponível em https://playground.wordpress.net/
  • Sobre o WP Playground: Visite esta seção para aprender sobre o WordPress Playground, o quão seguro ele é, o que você pode fazer com o Playground e algumas das suas limitações. Descubra como tirar proveito do WordPress Playground para Construir, Testar e Lançar os seus produtos.
  • Guias: Explore estes guias para aprender mais a fundo sobre alguns dos conceitos ou aplicações práticas mais populares do WordPress Playground!
  • Contribuir: O WordPress Playground é um projeto de código aberto (open-source) e todas as contribuições são bem-vindas. Você pode contribuir com o projeto ajudando com o código, com o design, com a documentação ou com a organização de tarefas. Nesta seção, você encontrará informações sobre como contribuir para o projeto.
  • Links e recursos: Uma compilação de links úteis e recursos relacionados com o WordPress Playground.

Aprofunde um pouco mais​

Se você é um desenvolvedor ou um usuário técnico, talvez queira ver diretamente as APIs do WP Playground que estão disponíveis:

  • Leia sobre APIs do Playground e sobre alguns conceitos básicos.
  • Links e recursos
  • Escolha a API adequada para a sua aplicação:
    • API de Consulta permite realizar operações básicas usando apenas parâmetros de consulta.
    • API de Blueprints oferece um alto grau de controle com um único arquivo JSON.
    • API JavaScript oferece controle total por meio de um cliente JavaScript a partir de um pacote npm.
  • Aprofunde-se na arquitetura e aprenda como o WP Playground funciona internamente.

Envolva-se​

O WordPress Playground é um projeto de código aberto (open-source) e todas as contribuições são bem-vindas, desde código a design, de documentação à organização de tarefas do projeto. Não se preocupe, você não precisa saber WebAssembly para contribuir para o projeto!

  • Dê uma olhada no Manual do Colaborador (Contributors Handbook) para tudo o que você precisa saber para contribuir com o projeto.
  • Junte-se ao canal #playground no Slack (na página do Slack do WordPress você encontrará as informações sobre como acessar o Slack do WordPress)

Como em todos os projetos do WordPress, queremos garantir um ambiente seguro e acolhedor para todos. Com isso em mente, espera-se que todos os contribuidores cumpram o nosso código de conduta.
