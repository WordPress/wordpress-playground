# WordPress Playground para todas as pessoas

<!--
**WordPress Playground lets you run WordPress instantly—no server, no setup, no risk.** It works in your browser at [playground.wordpress.net](https://playground.wordpress.net), and developers can also use it via CLI, Node.js, or embedded in their own apps. But you don't need to be technical to benefit from it.
-->

**O WordPress Playground permite executar o WordPress imediatamente, sem servidor, configuração ou risco.** Ele funciona no navegador em [playground.wordpress.net](https://playground.wordpress.net). Desenvolvedores também podem usá-lo pela CLI, pelo Node.js ou incorporado aos próprios aplicativos, mas você não precisa ter conhecimento técnico para aproveitar seus benefícios.

## Think of It Like a Car Simulator
-->

## Pense nele como um simulador de carro

<!--
A car simulator gives you a steering wheel, pedals, and virtual streets. Practice driving, hit cones, make mistakes — nothing bad happens. No real car gets damaged. Want to try again? Just restart.
-->

Um simulador de carro oferece volante, pedais e ruas virtuais. Você pode praticar, bater em cones e cometer erros sem causar danos. Nenhum carro real é danificado. Quer tentar novamente? Basta reiniciar.

<!--
WordPress Playground works the same way. It gives you a complete WordPress site to experiment with, but nothing you do affects any real website. Make changes, break things, learn from mistakes — then start fresh whenever you want.
-->

O WordPress Playground funciona da mesma forma. Ele oferece um site WordPress completo para você experimentar, mas nada do que fizer afeta um site real. Faça alterações, provoque falhas, aprenda com os erros e recomece quando quiser.

## What Can You Do with Playground?
-->

## O que você pode fazer com o Playground?

<!--
When you visit [playground.wordpress.net](https://playground.wordpress.net), you get a WordPress site running entirely in your browser. You can:
-->

Ao acessar [playground.wordpress.net](https://playground.wordpress.net), você recebe um site WordPress executado inteiramente no navegador. Você pode:

<!--
- Install plugins and themes
- Edit pages and create content
- Change WordPress and PHP versions
- Explore features you've never tried before
-->

- Instalar plugins e temas
- Editar páginas e criar conteúdo
- Alterar as versões do WordPress e do PHP
- Explorar recursos que ainda não conhece

<!--
By default, WordPress Playground loads a landing page that introduces Playground. To start with a plain WordPress install, open **New** in the Dock and choose **Vanilla WordPress** from the Blueprint gallery.
-->

Por padrão, o WordPress Playground carrega uma página inicial que apresenta o Playground. Para começar com uma instalação simples do WordPress, abra **Novo** no Dock e escolha **Vanilla WordPress** na galeria de Blueprints.

<!--
![The Dock New button and the Blueprint gallery with Vanilla WordPress selected](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/open-blueprints-gallery.webp)
-->

![O botão Novo do Dock e a galeria de Blueprints com o Vanilla WordPress selecionado](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/open-blueprints-gallery.webp)

## If You're Learning WordPress

## Se você está aprendendo WordPress

<!--
Are you new to WordPress or trying to understand features like the Site Editor or the new features of the latest WordPress Release? Playground is your perfect practice space.
-->

Você está começando a usar o WordPress ou tentando entender recursos como o Editor do site e as novidades da versão mais recente? O Playground é um ótimo espaço para praticar.

<!--
### Explore How Pages Are Built
-->

### Explorar como as páginas são criadas

<!--
Playground logs you in as an administrator, so you can edit any page. Click **Edit** for editing posts and **Edit Site** to update the website layout in the top toolbar to open the editor.
-->

O Playground conecta você como administrador para que possa editar qualquer página. Na barra superior, clique em **Editar** para editar posts ou em **Editar site** para alterar o layout do site.

<!--
![Editing WordPress websites](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/edit-sites-with-playground.webp)
-->

![Edição de sites WordPress](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/edit-sites-with-playground.webp)

<!--
Want to understand how a page layout was created? Open the **List View** (the three horizontal lines icon) to see every block that makes up the page.
-->

Quer entender como o layout de uma página foi criado? Abra a **Visualização em lista**, identificada pelo ícone de três linhas horizontais, para ver todos os blocos que compõem a página.

<!--
![Site Editor List view](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/site-editor-list-view.webp)
-->

![Visualização em lista do Editor do site](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/site-editor-list-view.webp)

<!--
You can inspect columns, headings, images, and buttons — and see exactly how they're arranged. This is a powerful way to learn by example.
-->

Você pode inspecionar colunas, títulos, imagens e botões e ver exatamente como estão organizados. Essa é uma maneira eficiente de aprender com exemplos.

## If You Own a WordPress Site

## Se você tem um site WordPress

<!--
Running a live website means every change risks breaking something. Playground lets you test before you commit.
-->

Em um site publicado, cada alteração traz o risco de causar uma falha. O Playground permite testar antes de confirmar a mudança.

<!--
### Test Plugins Before Installing
-->

### Testar plugins antes de instalar

<!--
Curious about a new SEO plugin? Want to compare two contact form options? Install them in Playground first:
-->

Quer conhecer um novo plugin de SEO ou comparar duas opções de formulário de contato? Instale os plugins primeiro no Playground:

<!--
1. Open [playground.wordpress.net](https://playground.wordpress.net)
2. Go to **Plugins → Add New**
3. Search for and install any plugin
4. Test it thoroughly
-->

1. Abra [playground.wordpress.net](https://playground.wordpress.net)
2. Acesse **Plugins → Adicionar plugin**
3. Pesquise e instale qualquer plugin
4. Teste-o com cuidado

<!--
Your real site stays untouched while you evaluate whether the plugin fits your needs.
-->

Seu site real não é alterado enquanto você avalia se o plugin atende às suas necessidades.

<!--
![Installing Plugins](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/installing-plugins.webp)
-->

![Instalação de plugins](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/installing-plugins.webp)

<!--
### Preview Theme Changes
-->

### Pré-visualizar alterações de tema

<!--
Thinking about switching themes? Test your new theme in Playground to see how it handles your content — without disrupting your visitors.
-->

Está pensando em trocar de tema? Teste o novo tema no Playground para ver como ele apresenta seu conteúdo, sem interromper a experiência dos visitantes.

<!--
### Compare Options Side by Side
-->

### Comparar opções lado a lado

<!--
Open multiple browser tabs with different Playground setups. Compare plugin A versus plugin B, or see how your content looks in different themes. Make informed decisions before touching your production site.
-->

Abra várias abas do navegador com configurações diferentes do Playground. Compare o plugin A com o plugin B ou veja como seu conteúdo aparece em temas diferentes. Assim, você pode tomar decisões fundamentadas antes de alterar o site em produção.

<div class="callout callout-info">

**Seu site real permanece seguro**

Every Playground runs independently in your browser. Nothing syncs to any external server, and nothing affects your live WordPress installation.

Cada Playground é executado de forma independente no navegador. Nada é sincronizado com um servidor externo e nada afeta sua instalação publicada do WordPress.

## If You Use WordPress Daily

## Se você usa o WordPress todos os dias

<!--
Even experienced WordPress users benefit from a safe testing environment.
-->

Mesmo pessoas experientes no WordPress se beneficiam de um ambiente seguro para testes.

<!--
### Make Design Experiments
-->

### Fazer experimentos de design

<!--
Want to try a different font size? Adjust spacing? Change colors? Load a Playground with the same theme that you are using in production and edit it freely:
-->

Quer testar outro tamanho de fonte, ajustar o espaçamento ou mudar as cores? Carregue um Playground com o mesmo tema usado em produção e edite-o livremente:

<!--
1. Open any page in the editor
2. Select a block and modify its settings
3. See the results immediately
-->

1. Abra qualquer página no editor
2. Selecione um bloco e modifique suas configurações
3. Veja o resultado imediatamente

<!--
If you like what you see, recreate those changes on your real site. If not,
start another Playground. The experiment may remain as a recent autosave until
newer autosaves replace it.
-->

Se gostar do resultado, reproduza as alterações no site real. Caso contrário, inicie outro Playground. O experimento pode permanecer como um salvamento automático recente até ser substituído por salvamentos mais novos.

<!--
## Yes, You Can Save Your Work
-->

## Sim, você pode salvar seu trabalho

<!--
**Playground doesn't have to be temporary.** You can save your progress and return to it later.
-->

**O Playground não precisa ser temporário.** Você pode salvar seu progresso e voltar a ele depois.

<!--
### Save to Your Browser
-->

### Salvar no navegador

<!--
New Playgrounds are autosaved when browser storage is available. The Dock shows the save status next to the address field.
-->

Novos Playgrounds são salvos automaticamente quando o armazenamento do navegador está disponível. O Dock mostra o status de salvamento ao lado do campo de endereço.

<!--
![The Autosaved status in the Dock](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/unsaved-playground-warning.webp)
-->

![O status Salvo automaticamente no Dock](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/guides/unsaved-playground-warning.webp)

<!--
Open **Your Playgrounds** from the Dock to return to recent autosaves. Playground keeps up to five recent autosaves.
-->

Abra **Seus Playgrounds** no Dock para voltar aos salvamentos automáticos recentes. O Playground mantém até cinco deles.

<!--
![The Your Playgrounds pane with the current Playground](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/dock/your-playgrounds.webp)
-->

![O painel Seus Playgrounds com o Playground atual](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/dock/your-playgrounds.webp)

<!--
To keep an autosave permanently, click the **Autosaved** status in the Dock, choose **Save in browser storage**, and save it.
-->

Para manter um salvamento automático permanentemente, clique no status **Salvo automaticamente** no Dock, escolha **Salvar no armazenamento do navegador** e salve-o.

<!--
![The Store permanently pane with a Playground name and the Save button](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/saving-playground.webp)
-->

![O painel Armazenar permanentemente com o nome do Playground e o botão Salvar](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/saving-playground.webp)

<!--
### Download as a ZIP File
-->

### Baixar como arquivo ZIP

<!--
Need to move your work elsewhere? Open **Export** and choose **Download as .zip**. The ZIP contains the current files, database, plugins, themes, uploads, and edits. You can restore it later with **New → Import zip** or host it on a server that supports PHP and SQLite.
-->

Precisa mover seu trabalho? Abra **Exportar** e escolha **Baixar como .zip**. O ZIP contém os arquivos, o banco de dados, os plugins, os temas, os arquivos enviados e as edições atuais. Você pode restaurá-lo depois com **Novo → Importar zip** ou hospedá-lo em um servidor compatível com PHP e SQLite.

<!--
![The Export pane with Download as .zip highlighted](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/export-playground.webp)
-->

![O painel Exportar com Baixar como .zip destacado](https://raw.githubusercontent.com/WordPress/wordpress-playground/refs/heads/trunk/packages/docs/site/static/img/export-playground.webp)

<div class="callout callout-tip">

<!--
**Keep a portable backup**
-->

**Mantenha um backup portátil**

<!--
Browser storage belongs to your browser profile and can be cleared or evicted. Export a ZIP when you need a file you can move or archive.
-->

O armazenamento do navegador pertence ao perfil do navegador e pode ser limpo ou removido. Exporte um ZIP quando precisar de um arquivo que possa mover ou arquivar.

</div>
