# Documentação de Blueprints

:::tip
Confira a [Galeria de Blueprints](https://github.com/WordPress/blueprints/blob/trunk/GALLERY.md) para explorar exemplos de código do mundo real usando WordPress Playground para iniciar um site WordPress com uma variedade de configurações.
:::

Olá! Bem-vindo à documentação dos Blueprints do WordPress Playground.

Blueprints são arquivos JSON para configurar sua própria instância do WordPress Playground. Este subsite (Documentação de Blueprints) é onde você encontrará todas as informações necessárias para usar as Blueprints.

<p class="docs-hubs">A documentação do WordPress Playground é distribuída em quatro hubs separados (subsites):</p>

-   [**Documentação**](/) – Introdução ao WP Playground, guias de início rápido e seu ponto de entrada para Documentação do WP Playground.
-   👉 [**Blueprints**](/blueprints) (você está aqui) – Blueprints são arquivos JSON para configurar sua instância do WordPress Playground. Aprenda sobre suas possibilidades neste hub de documentação dos Blueprints.
-   [**Desenvolvedores**](/developers) – WordPress Playground foi criado como uma ferramenta programável. Descubra tudo o que você pode fazer com ele a partir do seu código no hub de documentação de desenvolvedores.
-   [**Referência de API**](/api) – Todas as APIs expostas pelo WordPress Playground

## Navegando pelo hub de documentação de Blueprints

Este hub de documentação é focado em informações de Blueprints e está dividido nas seguintes seções principais:

-   [Introdução aos Blueprints](/blueprints/getting-started): Guia de início rápido para configurar uma instância do WordPress Playground usando arquivos JSON de Blueprint.

-   [Tutorial - Blueprints 101](/blueprints/tutorial) - Curso intensivo da API de Blueprints. O tutorial o guiará através do processo completo de criar um blueprint que carrega um tema e plugin (entre outras coisas).

-   [Formato de Dados de Blueprint](/blueprints/data-format): Arquivos JSON de Blueprint definem sua instância do Playground com várias propriedades. Esta seção destaca as principais propriedades que você precisa conhecer.

-   [Usando Blueprints](/blueprints/using-blueprints): Aprenda nesta seção diferentes maneiras de usar Blueprints.

-   [Passos](/blueprints/steps): Referência de API de todos os passos disponíveis que podem ser definidos em um blueprint para executar tarefas como login, ativação de plugin/tema, operações de arquivo e muito mais.

-   [Pacotes de Blueprint](/blueprints/bundles): Aprenda como criar e usar pacotes de Blueprint - pacotes independentes que incluem um Blueprint e todos os seus recursos.

-   [Exemplos](/blueprints/examples): Compilação de exemplos de Blueprint para várias configurações do WordPress Playground, incluindo instalação de temas/plugins, execução de código PHP, habilitação de recursos e carregamento de versões específicas do WordPress.

-   [Solucionar problemas e depurar Blueprints](/blueprints/troubleshoot-and-debug): Dicas e ferramentas para solucionar problemas e depurar Blueprints.
