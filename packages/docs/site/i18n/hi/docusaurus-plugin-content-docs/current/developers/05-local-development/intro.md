<!-- ## Local WordPress Development with Playground -->

## Playground के साथ लोकल WordPress डेवलपमेंट {#local-wordpress-development-with-playground}

<!-- Playground offers various development environments to streamline setting up and managing WordPress sites. -->

Playground कई तरह के डेवलपमेंट एनवायरनमेंट देता है, जिनसे WordPress साइटें सेट अप करना और संभालना आसान हो जाता है।

<!-- For a quick start, use a [public Playground web instance](/web-instance) at https://playground.wordpress.net/. Alternatively, you can [host your own WordPress Playground](/developers/architecture/host-your-own-playground). -->

जल्दी शुरू करने के लिए https://playground.wordpress.net/ पर [सार्वजनिक Playground वेब इंस्टेंस](/web-instance) का उपयोग करें। इसके अलावा, आप [अपना खुद का WordPress Playground होस्ट कर सकते हैं](/developers/architecture/host-your-own-playground)।

<!-- Playground also provides tools for local WordPress development, prioritizing ease of installation and usability: -->

Playground लोकल WordPress डेवलपमेंट के लिए टूल भी देता है, जिनमें आसानी से स्थापित करने और उपयोग करने पर ज़ोर दिया गया है:

<!-- - **[@wp-playground/cli](/developers/local-development/wp-playground-cli):** A command-line tool to quickly launch a WordPress site from your terminal.
- **[Visual Studio Code Extension](/developers/local-development/vscode-extension):** Integrates WordPress development directly into VS Code for a seamless experience within the popular editor. -->

- **[@wp-playground/cli](/developers/local-development/wp-playground-cli):** एक कमांड-लाइन टूल, जिससे आप अपने टर्मिनल से WordPress साइट जल्दी लॉन्च कर सकते हैं।
- **[Visual Studio Code एक्सटेंशन](/developers/local-development/vscode-extension):** WordPress डेवलपमेंट को सीधे VS Code में ले आता है, ताकि आप इस लोकप्रिय एडिटर के अंदर ही बिना रुकावट काम कर सकें।

<!-- For those needing more control, Playground offers tools for Node.js: -->

जिन्हें ज़्यादा नियंत्रण चाहिए, उनके लिए Playground Node.js के टूल देता है:

<!-- - **[WordPress Playground in Node.js](/developers/local-development/php-wasm-node):** For low-level control over the WebAssembly PHP build, explore the [`@php-wasm/node` package](https://www.npmjs.com/package/@php-wasm/node), which includes the PHP WebAssembly runtime. -->

- **[Node.js में WordPress Playground](/developers/local-development/php-wasm-node):** WebAssembly PHP बिल्ड पर निचले स्तर के नियंत्रण के लिए [`@php-wasm/node` पैकेज](https://www.npmjs.com/package/@php-wasm/node) देखें, जिसमें PHP WebAssembly रनटाइम शामिल है।
