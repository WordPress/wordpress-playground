# लॉन्च

<!-- Reach your clients or customers faster. Showcase your product, let users try it live, or launch it in the App Store with zero lead time. -->

अपने क्लाइंट या ग्राहकों तक तेज़ी से पहुँचें। अपना प्रोडक्ट दिखाएँ, उपयोगकर्ताओं को उसे लाइव आज़माने दें, या बिना किसी इंतज़ार के उसे App Store में लॉन्च करें।

<!-- ## Embed interactive product demos on websites. -->

## वेबसाइटों पर इंटरैक्टिव प्रोडक्ट डेमो एम्बेड करें। {#embed-interactive-product-demos-on-websites}

<!-- Leverage [blueprints'](/blueprints) potential to create interactive demos of your plugins or themes. For example, you can provide a link to your users/clients to showcase how your custom plugin integrates with an adapted theme, demonstrating their combined functionality and appearance. -->

अपने प्लगइन या थीम के इंटरैक्टिव डेमो बनाने के लिए [ब्लूप्रिंट](/blueprints) की क्षमता का पूरा फ़ायदा उठाएँ। उदाहरण के लिए, आप अपने उपयोगकर्ताओं/क्लाइंट को एक लिंक दे सकते हैं, जिससे वे देख सकें कि आपका कस्टम प्लगइन अपने हिसाब से बदली गई थीम के साथ कैसे जुड़ता है, और दोनों मिलकर कैसे काम करते हैं और कैसे दिखते हैं।

<!-- Read more about this at [How to use WordPress Playground for interactive demos](https://developer.wordpress.org/news/2024/04/25/how-to-use-wordpress-playground-for-interactive-demos/) -->

इसके बारे में और जानकारी [How to use WordPress Playground for interactive demos](https://developer.wordpress.org/news/2024/04/25/how-to-use-wordpress-playground-for-interactive-demos/) में पढ़ें।

<!-- Get inspiration about the type of interactive demos you can create at the [Blueprints Gallery](https://github.com/WordPress/blueprints/blob/trunk/GALLERY.md) -->

आप किस तरह के इंटरैक्टिव डेमो बना सकते हैं, इसके लिए [Blueprints गैलरी](https://github.com/WordPress/blueprints/blob/trunk/GALLERY.md) से प्रेरणा लें।

<!-- The [Blueprints builder](https://playground.wordpress.net/builder/builder.html) tool allows you edit your blueprint online and run it directly in a Playground instance. -->

[Blueprints बिल्डर](https://playground.wordpress.net/builder/builder.html) टूल से आप अपना ब्लूप्रिंट ऑनलाइन संपादित कर सकते हैं और उसे सीधे किसी Playground इंस्टेंस में चला सकते हैं।

ब्लूप्रिंट बनाने का एक और काम का टूल [WordPress Playground Step Library](https://akirk.github.io/playground-step-library/#) है। यह एक विज़ुअल इंटरफ़ेस देता है, जिसमें आप चरणों को ड्रैग करके या उन पर क्लिक करके WordPress Playground के लिए ब्लूप्रिंट बना सकते हैं। आप [अपने खुद के चरण भी बना सकते हैं](https://github.com/akirk/playground-step-library/#contributing)!

<!-- ## Embed demos in posts and pages with the WordPress Playground block -->

## WordPress Playground ब्लॉक से पोस्ट और पेज में डेमो एम्बेड करें {#embed-demos-in-posts-and-pages-with-the-wordpress-playground-block}

<!-- This [WordPress Playground block](https://wordpress.org/plugins/interactive-code-block/) allows you to embed WordPress Playground in your posts and pages. You can also include an interactive code editor to demonstrate and teach your readers how WordPress plugins are built. -->

यह [WordPress Playground ब्लॉक](https://wordpress.org/plugins/interactive-code-block/) आपको अपनी पोस्ट और पेज में WordPress Playground एम्बेड करने देता है। आप इसमें एक इंटरैक्टिव कोड एडिटर भी जोड़ सकते हैं, ताकि अपने पाठकों को दिखा और सिखा सकें कि WordPress प्लगइन कैसे बनाए जाते हैं।

<!-- With this block you have a straightforward and effective way to create live WordPress environments that can be embedded within your blog posts. -->

इस ब्लॉक से आपको लाइव WordPress एनवायरनमेंट बनाने का एक आसान और असरदार तरीका मिलता है, जिन्हें आप अपनी ब्लॉग पोस्ट में एम्बेड कर सकते हैं।

<div class="callout callout-info">

<!-- For any issues or questions about the WordPress Playground Block, please open a GitHub issue in the [playground-tools](https://github.com/WordPress/playground-tools) repository. -->

WordPress Playground ब्लॉक से जुड़ी किसी भी समस्या या सवाल के लिए, कृपया [playground-tools](https://github.com/WordPress/playground-tools) रिपॉज़िटरी में GitHub इश्यू खोलें।

</div>
