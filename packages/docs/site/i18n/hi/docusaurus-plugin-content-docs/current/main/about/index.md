# WordPress Playground के बारे में

<!-- ## What is WordPress Playground? -->

## WordPress Playground क्या है? {#what-is-wordpress-playground}

<!-- **WordPress Playground is the platform that lets you run WordPress instantly on any device without a host**. It allows you to experiment and learn about WordPress without affecting your live website. It's a virtual sandbox where you can play around with different features, designs, and settings in a safe and controlled environment. -->

**WordPress Playground एक ऐसा प्लेटफ़ॉर्म है जिससे आप बिना होस्ट के, किसी भी डिवाइस पर तुरंत WordPress चला सकते हैं**। इससे आप अपनी लाइव वेबसाइट पर असर डाले बिना WordPress के साथ प्रयोग कर सकते हैं और उसे सीख सकते हैं। यह एक वर्चुअल सैंडबॉक्स है, जहाँ आप सुरक्षित और नियंत्रित माहौल में अलग-अलग फ़ीचर, डिज़ाइन और सेटिंग्स के साथ प्रयोग कर सकते हैं।

<!--
WordPress Playground is your place to build, test, and launch:

- [Build](/about/build): WordPress Playground can help you to build products with WordPress. Use it from where you work best, whether that's in the browser, Node.js, mobile apps, VS Code, or elsewhere.
- [Test](/about/test): Upgrade your QA process with WordPress Playground. Quickly test your plugins or themes, experiment in a private sandbox, and create PRs from your WP Playground instance to any repo.
- [Launch](/about/launch): Use WordPress Playground to showcase your product, let users try it live, or launch it in the App Store with zero lead time.
-->

WordPress Playground में आप बना सकते हैं, परीक्षण कर सकते हैं और लॉन्च कर सकते हैं:

- [बिल्ड](/about/build): WordPress Playground की मदद से आप WordPress के साथ प्रोडक्ट बना सकते हैं। इसे वहीं से इस्तेमाल करें जहाँ आप सबसे अच्छा काम करते हैं, चाहे वह ब्राउज़र हो, Node.js हो, मोबाइल ऐप हों, VS Code हो या कोई और जगह।
- [टेस्ट](/about/test): WordPress Playground से अपनी QA प्रक्रिया को बेहतर बनाएँ। अपने प्लगइन या थीम का जल्दी परीक्षण करें, किसी निजी सैंडबॉक्स में प्रयोग करें, और अपने WP Playground इंस्टेंस से किसी भी रिपॉज़िटरी के लिए PR बनाएँ।
- [लॉन्च](/about/launch): अपना प्रोडक्ट दिखाने, उपयोगकर्ताओं को उसे लाइव आज़माने देने, या बिना किसी इंतज़ार के उसे App Store में लॉन्च करने के लिए WordPress Playground का उपयोग करें।

<!-- ## Why WordPress Playground? -->

## WordPress Playground क्यों? {#why-wordpress-playground}

<!-- ### Try themes and plugins on the fly -->

### थीम और प्लगइन तुरंत आज़माएँ {#try-themes-and-plugins-on-the-fly}

<!-- With WordPress Playground, you can explore any [theme](https://developer.wordpress.org/themes/getting-started/what-is-a-theme/). You can choose from a wide range of themes and see how they look on your site. You can also modify the colors, fonts, layouts, and other visual elements to create a unique design. -->

WordPress Playground में आप कोई भी [थीम](https://developer.wordpress.org/themes/getting-started/what-is-a-theme/) आज़मा सकते हैं। आप ढेर सारी थीम में से चुन सकते हैं और देख सकते हैं कि वे आपकी साइट पर कैसी दिखती हैं। अपना अलग डिज़ाइन बनाने के लिए आप रंग, फ़ॉन्ट, लेआउट और दूसरे विज़ुअल हिस्से भी बदल सकते हैं।

<!-- In addition to themes, you can experiment with plugins too. With WordPress Playground, you can install and test different plugins to see how they work and what they can do for your site. This allows you to explore and understand the capabilities of WordPress without worrying about breaking anything. -->

थीम के अलावा, आप प्लगइन के साथ भी प्रयोग कर सकते हैं। WordPress Playground में आप अलग-अलग प्लगइन स्थापित करके उनका परीक्षण कर सकते हैं, ताकि देख सकें कि वे कैसे काम करते हैं और आपकी साइट के लिए क्या कर सकते हैं। इससे आप कुछ भी टूटने की चिंता किए बिना WordPress की क्षमताओं को जान और समझ सकते हैं।

<!-- ### Create content on the go -->

### झटपट सामग्री बनाएँ {#create-content-on-the-go}

<!-- Another great feature of WordPress Playground is the ability to create and edit content. You can write blog posts, create pages, and add media like images and videos to your site. This helps you understand how to organize and structure your content effectively. -->

WordPress Playground की एक और बढ़िया खूबी है सामग्री बनाना और उसे संपादित करना। आप ब्लॉग पोस्ट लिख सकते हैं, पेज बना सकते हैं, और अपनी साइट पर चित्र और वीडियो जैसी मीडिया फ़ाइलें जोड़ सकते हैं। इससे आपको यह समझने में मदद मिलती है कि अपनी सामग्री को असरदार तरीके से कैसे व्यवस्थित करें और उसकी संरचना कैसे बनाएँ।

<!-- The content you create is limited to the Playground on your device and disappears once you leave it, so you are free to explore and play without risking breaking any actual site. -->

आपकी बनाई सामग्री आपके डिवाइस के Playground तक ही सीमित रहती है और Playground छोड़ते ही हट जाती है, इसलिए आप किसी असली साइट के टूटने का जोखिम उठाए बिना खुलकर प्रयोग कर सकते हैं।

<!-- But hey! You can also connect your Playground instance to a GitHub repo and create a PR to persist those changes. -->

और हाँ! आप अपने Playground इंस्टेंस को किसी GitHub रिपॉज़िटरी से जोड़कर एक PR भी बना सकते हैं, ताकि ये बदलाव बने रहें।

<!-- ### It's super safe -->

### यह पूरी तरह सुरक्षित है {#its-super-safe}

<!-- Overall, WordPress Playground provides a risk-free environment for beginners to learn and get hands-on experience with WordPress. It helps you to gain confidence and knowledge before making changes to your live website. -->

कुल मिलाकर, WordPress Playground शुरुआती लोगों को WordPress सीखने और उस पर खुद काम करके अनुभव पाने के लिए जोखिम-मुक्त माहौल देता है। इससे अपनी लाइव वेबसाइट में बदलाव करने से पहले आपका आत्मविश्वास और जानकारी बढ़ती है।

<div class="callout callout-tip">

<!-- Check the [guides section](/guides) to learn more about how to leverage WordPress Playground to test your themes and plugins and create content on the fly. -->

अपनी थीम और प्लगइन का परीक्षण करने और झटपट सामग्री बनाने में WordPress Playground का पूरा फ़ायदा कैसे उठाएँ, यह जानने के लिए [गाइड सेक्शन](/guides) देखें।

</div>

<!-- ## How does WordPress Playground work? -->

## WordPress Playground कैसे काम करता है? {#how-does-wordpress-playground-work}

<!-- When you first start using WordPress Playground, you'll be provided with a separate space where you can create and customise your own WordPress website. This space is completely isolated from your actual website. -->

जब आप पहली बार WordPress Playground का उपयोग शुरू करते हैं, तो आपको एक अलग जगह मिलती है, जहाँ आप अपनी खुद की WordPress वेबसाइट बना सकते हैं और उसे अपने हिसाब से बदल सकते हैं। यह जगह आपकी असली वेबसाइट से पूरी तरह अलग रहती है।

<!-- ### Streamed, not served. -->

### स्ट्रीम होता है, सर्व नहीं। {#streamed-not-served}

<!-- The WordPress you see when you open Playground in your browser is a WordPress that should function like any WordPress, with [a few limitations](/developers/limitations) and the important exception that it's not a permanent server with an internet address which will limit connections to some third-party services (automation, sharing, analysis, email, backups, etc.) in a persistent way. -->

जब आप अपने ब्राउज़र में Playground खोलते हैं, तो आपको जो WordPress दिखता है, वह किसी भी दूसरे WordPress की तरह ही काम करना चाहिए। बस इसकी [कुछ सीमाएँ](/developers/limitations) हैं, और एक अहम अंतर यह है कि यह इंटरनेट पते वाला कोई स्थायी सर्वर नहीं है। इस वजह से कुछ थर्ड-पार्टी सेवाओं (ऑटोमेशन, शेयरिंग, विश्लेषण, ईमेल, बैकअप वगैरह) से स्थायी रूप से जुड़े रहना सीमित रहेगा।

<!-- The loading screen and progress bar you see on Playground includes both the streaming of those foundational technologies to your browser and configuration steps from [WordPress Blueprints](/blueprints) (see [examples](/blueprints/examples)), so that a full server, WordPress software, Theme & Plugin solutions and configuration instructions can be streamed over-the-wire. -->

Playground पर दिखने वाली लोडिंग स्क्रीन और प्रोग्रेस बार में दो काम शामिल हैं: उन बुनियादी तकनीकों को आपके ब्राउज़र तक स्ट्रीम करना, और [WordPress Blueprints](/blueprints) ([उदाहरण](/blueprints/examples) देखें) के कॉन्फ़िगरेशन चरण। इस तरह पूरा सर्वर, WordPress सॉफ़्टवेयर, थीम और प्लगइन, और कॉन्फ़िगरेशन के निर्देश इंटरनेट पर स्ट्रीम किए जा सकते हैं।

<!-- ## What makes Playground different from running WordPress on a web server or local desktop app? -->

## Playground किसी वेब सर्वर या लोकल डेस्कटॉप ऐप पर WordPress चलाने से अलग कैसे है? {#what-makes-playground-different-from-running-wordpress-on-a-web-server-or-local-desktop-app}

<!-- Web applications like WordPress have long relied on server technologies [to run logic](/developers/architecture/wasm-php-overview) and [store data](/developers/architecture/wordpress#sqlite). -->

WordPress जैसे वेब ऐप्लिकेशन लंबे समय से [लॉजिक चलाने](/developers/architecture/wasm-php-overview) और [डेटा स्टोर करने](/developers/architecture/wordpress#sqlite) के लिए सर्वर तकनीकों पर निर्भर रहे हैं।

<!-- Using those technologies has meant either running a web server connected to the internet or using those technologies in a desktop service or app (sometimes called a "WordPress local environment") that either leans on a virtual server with the technologies installed or the underlying technologies on the current device. -->

इन तकनीकों के उपयोग का मतलब रहा है: या तो इंटरनेट से जुड़ा वेब सर्वर चलाना, या इन तकनीकों को किसी डेस्कटॉप सेवा या ऐप में इस्तेमाल करना (जिसे कभी-कभी "WordPress लोकल एनवायरनमेंट" कहा जाता है)। ऐसी सेवा या ऐप या तो किसी ऐसे वर्चुअल सर्वर पर निर्भर रहता है जिसमें ये तकनीकें स्थापित होती हैं, या मौजूदा डिवाइस पर मौजूद तकनीकों पर।

<!-- Playground is a novel way to stream server technologies—including WordPress (and WP-CLI)—as files that can then run in the browser. -->

Playground सर्वर तकनीकों को, जिनमें WordPress (और WP-CLI) भी शामिल हैं, ऐसी फ़ाइलों के रूप में स्ट्रीम करने का एक नया तरीका है जो फिर ब्राउज़र में चल सकती हैं।
