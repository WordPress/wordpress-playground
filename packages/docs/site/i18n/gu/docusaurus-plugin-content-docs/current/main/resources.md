## WordPress Playground સાથે બનાવેલ એપ્લિકેશન્સ {#apps-built-with-wordpress-playground}

- [અધિકૃત ડેમો](https://playground.wordpress.net/) અને [પ્રદર્શન એપ](https://developer.wordpress.org/playground) – થીમ ઇન્સ્ટોલ કરો, પ્લગિન અજમાવો, કેટલાક પૃષ્ઠો બનાવો અને તમે જે બનાવ્યું છે તે નિકાસ કરો
- [@wp-playground/cli](https://www.npmjs.com/package/@wp-playground/cli) – ત્વરિત WordPress વિકાસ વાતાવરણ માટે CLI ટૂલ
- [VS Code માટે WordPress Playground](https://marketplace.visualstudio.com/items?itemName=WordPressPlayground.wordpress-playground)
- લાઇવ અનુવાદો: [એપ](https://translate.wordpress.org/projects/wp-plugins/friends/dev/pl/default/playground/), [જાહેરાત](https://make.wordpress.org/polyglots/2023/04/19/wp-translation-playground/), [વધુ વિગતો](https://make.wordpress.org/polyglots/2023/05/08/translate-live-updates-to-the-translation-playground/)
- [ઇન્ટરેક્ટિવ કોડ બ્લોક](https://wordpress.org/plugins/interactive-code-block/) જે [HTML Tag Processor ટ્યુટોરિયલ](https://adamadam.blog/2023/02/16/how-to-modify-html-in-a-php-wordpress-plugin-using-the-new-tag-processor-api/) અને [Playground JS API ટ્યુટોરિયલ](https://wordpress.github.io/wordpress-playground/developers/apis/javascript-api/) ને સંચાલિત કરે છે
- [Gutenberg પુલ રિક્વેસ્ટ પૂર્વાવલોકન સાધન](https://playground.wordpress.net/gutenberg.html)
- [GraphQL REPL](https://www.wpgraphql.com/2023/06/15/announcing-the-wpgraphql-repl)
- [Blocknotes](https://twitter.com/adamzielin/status/1669478239771799552) – તમારા ફોન પર WordPress ચલાવતી પ્રથમ iOS એપ
- [wp.org પર પ્લગિન ડેમો](https://gist.github.com/adamziel/0fe3ffc1fb5202a907a87d055ee37135) – એક યુઝર સ્ક્રિપ્ટ જે WordPress.org પર પ્લગિન પૃષ્ઠોમાં "ડેમો" ટેબ ઉમેરે છે
- [WordPress પુલ રિક્વેસ્ટ પૂર્વાવલોકન સાધન](https://playground.wordpress.net/wordpress.html)
- [બે Playgrounds વચ્ચે સમન્વય](https://playground.wordpress.net/demos/sync.html)
- [Time Travel](https://playground.wordpress.net/demos/time-traveling.html)
- [WP-CLI](https://playground.wordpress.net/demos/wp-cli.html)
- [Blueprints નું PHP અમલીકરણ](https://playground.wordpress.net/demos/php-blueprints.html)
