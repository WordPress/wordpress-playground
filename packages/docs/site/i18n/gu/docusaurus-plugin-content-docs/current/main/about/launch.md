# લોન્ચ

તમારા ક્લાઈન્ટ્સ અથવા ગ્રાહકો સુધી ઝડપથી પહોંચો. તમારું પ્રોડક્ટ પ્રદર્શિત કરો, વપરાશકર્તાઓને તેને લાઈવ અજમાવવા દો, અથવા ઝીરો લીડ ટાઈમ સાથે એપ સ્ટોરમાં લોન્ચ કરો.

## વેબસાઇટ્સ પર ઇન્ટરેક્ટિવ પ્રોડક્ટ ડેમો એમ્બેડ કરો.

[બ્લુપ્રિન્ટ્સ](/blueprints) ની સંભાવનાનો લાભ લઈને તમારા પ્લગઇન્સ અથવા થીમ્સના ઇન્ટરેક્ટિવ ડેમો બનાવો. ઉદાહરણ તરીકે, તમારા કસ્ટમ પ્લગઇન એડેપ્ટેડ થીમ સાથે કેવી રીતે સંકલિત થાય છે તે પ્રદર્શિત કરવા માટે, તેમના સંયુક્ત કાર્યક્ષમતા અને દેખાવ દર્શાવીને, તમે તમારા વપરાશકર્તાઓ/ગ્રાહકોને લિંક પ્રદાન કરી શકો છો.

આ વિશે વધુ વાંચો [વર્ડપ્રેસ પ્લેગ્રાઉન્ડનો ઉપયોગ ઇન્ટરેક્ટિવ ડેમો માટે કેવી રીતે કરવો](https://developer.wordpress.org/news/2024/04/25/how-to-use-wordpress-playground-for-interactive-demos/) પર

તમે કયા પ્રકારના ઇન્ટરેક્ટિવ ડેમો બનાવી શકો છો તે વિશે પ્રેરણા મેળવો [બ્લુપ્રિન્ટ્સ ગેલેરી](https://github.com/WordPress/blueprints/blob/trunk/GALLERY.md) પર

[બ્લુપ્રિન્ટ્સ બિલ્ડર](https://playground.wordpress.net/builder/builder.html) ટૂલ તમને તમારી બ્લુપ્રિન્ટ ઓનલાઈન એડિટ કરવા અને તેને સીધું પ્લેગ્રાઉન્ડ ઇન્સ્ટન્સમાં ચલાવવાની મંજૂરી આપે છે.

બ્લુપ્રિન્ટ બનાવવા માટેનું બીજું એક સરળ ટૂલ છે [વર્ડપ્રેસ પ્લેગ્રાઉન્ડ સ્ટેપ લાઇબ્રેરી](https://akirk.github.io/playground-step-library/#) ટૂલ જે વર્ડપ્રેસ પ્લેગ્રાઉન્ડ માટે બ્લુપ્રિન્ટ બનાવવા માટેના પગલાઓને ખેંચવા અથવા ક્લિક કરવા માટે વિઝ્યુઅલ ઇન્ટરફેસ પૂરું પાડે છે. તમે [તમારા પોતાના પગલાઓ પણ બનાવી શકો છો](https://github.com/akirk/playground-step-library/#contributing)!

## વર્ડપ્રેસ પ્લેગ્રાઉન્ડ બ્લોક સાથે પોસ્ટ્સ અને પેજીસમાં ડેમો એમ્બેડ કરો

આ [વર્ડપ્રેસ પ્લેગ્રાઉન્ડ બ્લોક](https://wordpress.org/plugins/interactive-code-block/) તમને તમારી પોસ્ટ્સ અને પેજીસમાં વર્ડપ્રેસ પ્લેગ્રાઉન્ડ એમ્બેડ કરવાની મંજૂરી આપે છે. તમે તમારા વાચકોને વર્ડપ્રેસ પ્લગઇન્સ કેવી રીતે બનાવવામાં આવે છે તે દર્શાવવા અને શીખવવા માટે ઇન્ટરેક્ટિવ કોડ એડિટર પણ શામેલ કરી શકો છો.

આ બ્લોક સાથે તમારી પાસે એક સીધો અને અસરકારક રસ્તો છે લાઈવ વર્ડપ્રેસ એન્વાયર્નમેન્ટ્સ બનાવવા માટે જેને તમારી બ્લોગ પોસ્ટ્સની અંદર એમ્બેડ કરી શકાય છે.

:::info
વર્ડપ્રેસ પ્લેગ્રાઉન્ડ બ્લોક વિશે કોઈપણ સમસ્યાઓ અથવા પ્રશ્નો માટે, કૃપા કરીને [playground-tools](https://github.com/WordPress/playground-tools) રીપોઝિટરીમાં GitHub ઇશ્યુ ખોલો.
:::

## એપ સ્ટોરમાં વર્ડપ્રેસ ચલાવતી નેટિવ એપ્લિકેશન મૂકો.

[પ્લેગ્રાઉન્ડ દ્વારા નેટિવ આઈઓએસ એપ્લિકેશનમાં વાસ્તવિક વર્ડપ્રેસ સાઇટ કેવી રીતે શિપ કરવી?](../guides/wordpress-native-ios-app) ગાઈડમાં આ યુઝ કેસ માટેની માહિતી તપાસો.
