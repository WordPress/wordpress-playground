# Blueprint v1

Blueprint v1 is the original Blueprint format. A v1 Blueprint has no `version` field.

Current Playground runners still accept v1 Blueprints, but v1 is now a legacy format. Use
[Blueprint v2](/blueprints/v2) for new work.

The legacy label describes the documentation path, not a runtime removal. No v1
end-of-support date has been announced.

Migrating from v1 to v2 is currently a manual process. Follow the
[migration guide](/blueprints/v2/migrate-from-v1) to update an existing Blueprint.
