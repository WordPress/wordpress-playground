# Blueprint v2 tutorials

Choose the result you want to share. Each tutorial starts with a working
Blueprint, shows you what to replace, and ends with a checklist you can hand to
another person.

| Your goal                                                                                        | Best for                         | What you will publish                                                           |
| ------------------------------------------------------------------------------------------------ | -------------------------------- | ------------------------------------------------------------------------------- |
| [Add a Preview to a WordPress.org plugin](/blueprints/v2/tutorials/plugin-preview)               | Plugin committers                | A tested Preview button on the plugin's WordPress.org page                      |
| [Build an interactive theme demo](/blueprints/v2/tutorials/theme-demo)                           | Theme authors and reviewers      | A front-end demo with a chosen theme, representative content, and media         |
| [Create a one-click bug or pull-request reproduction](/blueprints/v2/tutorials/bug-reproduction) | Bug reporters and code reviewers | One pinned test environment that opens in a browser and runs from the CLI or CI |

New to v2? Complete [Blueprints 101](/blueprints/v2/blueprints-101) first. It
takes you from a one-click example to running and sharing your own Blueprint.

Every tutorial uses one working example for the Run button and the complete
JSON. You can start in the browser and use the CLI sections only when you need
local or automated runs.
