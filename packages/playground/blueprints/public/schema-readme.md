The JSON schema stored in this directory describes how to validate
Blueprints v1 and v2 and is autogenerated from the Blueprints TypeScript
types.

The public Blueprint schema validator stored in this directory validates
Blueprints v1 and v2 and is autogenerated from the public Blueprints JSON
schema.

The `blueprint-v1-schema-validator.js` file is an internal compatibility
validator for the v1 compiler. It intentionally remains v1-only so
`compileBlueprintV1()` cannot accidentally accept Blueprint v2 declarations.

Whenever the types are modified, the schema and validator need to be
rebuilt using `nx build playground-blueprints` and then committed to
the repository.

Unfortunately, they are not auto-rebuilt in `npm run dev` mode as the
`dts-bundle-generator` utility we use for type rollups does not support
watching for changes.
