consejo

Hay un conjunto de redirecciones disponibles para facilitar el acceso a algunas de las herramientas relacionadas con Playground:

  • https://playground.wordpress.net/ → Instancia de Playground
  • https://playground.wordpress.net/docs → Documentación de Playground
  • https://playground.wordpress.net/builder → Constructor de Blueprints de Playground
  • https://playground.wordpress.net/wordpress → Visor de PR de Playground para WordPress
  • https://playground.wordpress.net/gutenberg → Visor de PR de Playground para Gutenberg
  • https://playground.wordpress.net/proxy → Servicio Proxy de Playground (ver URLReference para más información)
