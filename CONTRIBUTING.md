# Contributing to WordPress Playground

WordPress Playground is an open-source project, and contributions of all kinds are welcome — code, documentation, translations, design, and issue triage.

The full, up-to-date guide lives in the **[Playground Handbook](https://developer.wordpress.org/playground/handbook/contributing/)**. Start there for setup instructions, coding conventions, and the pull request process.

## Ways to contribute

- **Code** — see the [code contributions guide](https://developer.wordpress.org/playground/handbook/contributing/code/) and [coding principles](https://developer.wordpress.org/playground/handbook/contributing/coding-standards/).
- **Documentation** — see [documentation contributions](https://developer.wordpress.org/playground/handbook/contributing/documentation/).
- **Translations** — see [contributions to translations](https://developer.wordpress.org/playground/handbook/contributing/translations/).
- **Bug reports** — [open a new issue](https://github.com/WordPress/wordpress-playground/issues/new).
- **Ideas and discussion** — start a [GitHub Discussion](https://github.com/WordPress/wordpress-playground/discussions).
- **Triaging issues** — see the [triaging section](https://developer.wordpress.org/playground/handbook/contributing/#triaging-issues) of the handbook.
- **WordCamp Contributor Day** — see the [Contributor Day guide](https://developer.wordpress.org/playground/handbook/contributing/contributor-day/) and the [Contributor Badge](https://developer.wordpress.org/playground/handbook/contributing/contributor-badge/).

## Code of Conduct

All contributors are expected to follow the WordPress project's [Community Code of Conduct](https://make.wordpress.org/handbook/community-code-of-conduct/).
