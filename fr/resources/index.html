astuce

Un ensemble de redirections est en place pour faciliter l'accès à certains outils liés à Playground :

  • https://playground.wordpress.net/ → instance Playground
  • https://playground.wordpress.net/docs → Documentation Playground
  • https://playground.wordpress.net/builder → Constructeur de blueprints Playground
  • https://playground.wordpress.net/wordpress → Visualiseur de PR Playground pour WordPress
  • https://playground.wordpress.net/gutenberg → Visualiseur de PR Playground pour Gutenberg
  • https://playground.wordpress.net/proxy → Service Proxy Playground (voir URLReference pour plus d'information)
