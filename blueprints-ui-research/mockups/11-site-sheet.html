When it opens:

Everything above is one blueprint.json — press Run to build a fresh site from it. Nothing is installed until then.

The bet: the entire Blueprint fits one screen as a single paper sheet, so nothing hides behind tabs or scrolling. Every item in every collection uses one row grammar — icon, name, one plain fact, control — so the pattern is learned once and reused everywhere. Facts you can change are pills with visible carets; the only saturated color on the sheet is the Run button. Every count and summary is computed from the same state object that generates the JSON, so the sheet can never disagree with itself.
