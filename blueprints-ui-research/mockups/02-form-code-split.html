DESIGN 2 Form ⇄ Code split — one document, two skill levels, round-tripped. Developer-first. about this ▲

The whole editor is a projection of one blueprint.json. Form on the left, live JSON on the right; edit either and the other updates. Clicking a form group jumps to and highlights the matching JSON node (Stoplight Studio's signature move). Devs are never blocked — the JSON is right there and canonical; non-devs never have to look right. The repo already auto-generates the Blueprint JSON Schema from the TypeScript step types, so live validation + autocomplete come nearly for free.

Lenient validation (Francesco Bigiarini's HTML-browser analogy): the amber row is a warning, not a blocker — Playground runs the valid steps and flags the rest. The Full configuration tab is a read-only “merged” lens showing the resolved plan after macros/imports expand (GitLab CI).

The traps this design must avoid (from the survey): destructive mode-switch (JSON is source of truth — preserve unmodeled keys), formatting/key-order churn (format-preserving serialization), and invalid-code lockout (keep the last-good form, never crash).
