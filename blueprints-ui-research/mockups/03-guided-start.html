DESIGN 3 Guided Start — the on-ramp for non-devs. Goal → prefilled starter → editor. about this ▲

The blank-page antidote and the answer to Adam's “Add Site form” use case. Three short, linear steps (staged disclosure — appropriate only for first-run, never for editing): pick a goal → review a detected-and-prefilled starter (Vercel's “never a blank form”) → drop into the full editor pre-populated. The runtime uses Local by Flywheel's Preferred / Custom fork — your exact non-dev-vs-dev split expressed as one radio choice.

Entry points cover Adam's other two use cases too: Fork an existing Blueprint (pre-populated, iterate) and Record from my running site (the 80/20 “Blueprint valet” — jdevalk / Draganescu). A persistent Shopify-style checklist gives momentum without trapping anyone. Crucially, “Customize” lands in the real editor, not a read-only dead end.
