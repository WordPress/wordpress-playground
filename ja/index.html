WordPress Playground ドキュメント

公式の Playground ウェブサイトをお探しですか？

WordPress Playground ウェブサイトは wordpress.org/playground/ に移動しました。現在ご覧のサイトはドキュメントをホストしています。

👋 こんにちは ! WordPress Playground ドキュメントへようこそ。

Playground は、WordPress を試したり学んだりするためのオンラインツールです。このサイト（ドキュメント）では、Playground の使用を開始するために必要なすべての情報を見つけることができます。

WordPress Playground ドキュメントは、4つの独立したハブ（サブサイト）に分散されています。

  • 👉 ドキュメント (現在こちら) – WP Playground の紹介、入門ガイド、WP Playground ドキュメントへの入り口。
  • ブループリント – ブループリントは、WordPress Playground インスタンスをセットアップするための JSON ファイルです。ブループリントドキュメントハブでその可能性について学びましょう。
  • 開発者向け – WordPress Playground はプログラミング可能なツールとして作成されました。開発者向けドキュメントハブで、コードからできるすべてのことを見つけてください。
  • API リファレンス – WordPress Playground によって公開されているすべての API

このドキュメントハブのナビゲーション​

このドキュメントハブは WordPress Playground の開始に焦点を当てており、以下の主要なセクションに分かれています。

  • クイックスタートガイド: WordPress Playground を始めたばかりの方はこちらをご覧ください。WordPress Playground をすぐに起動して、新しい WordPress サイトを開始したり、ブロック/テーマ/プラグインを試したり、または特定の WordPress/PHP バージョンをテストしたりできます。
  • Playground ウェブインスタンス: https://playground.wordpress.net/ で利用できる Playground インスタンスについて詳しく学びましょう。
  • Playground について: WordPress Playground について、その安全性、できること、現在の制限事項などを知るには、このセクションをご覧ください。 構築、テスト、公開に WordPress Playground をどのように活用できるかを発見してください。
  • ガイド: 新しいスキルを習得し、ステップバイステップの手順を見つけ、貴重な洞察を得るための包括的なガイドをご覧ください。深く掘り下げて学び、成長しましょう !
  • 貢献: WordPress Playground はオープンソースプロジェクトであり、コードからデザイン、ドキュメントからトリアージまで、すべての貢献者を歓迎します。貢献方法についてはこちらをご覧ください。
  • リンクとリソース: WordPress Playground に関連する役立つリンクとリソースの素敵なまとめ。

最初のステップ​

開発者、非技術系のユーザー、貢献者のいずれであっても、これらのドキュメントは学習の旅を始めるにあたってあなたを導きます。

  • 5 分で WordPress Playground の使用を開始 (そして デモサイト をチェック)
  • WordPress Playground で 開発を始める
  • Playground をセットアップ不要の ローカル開発環境 として使用する
  • 制限事項 について読む
  • WordCamp 貢献者デー
ヒント

WordPress 開発者ブログ の Playground の紹介: ブラウザで WordPress を実行する のブログ記事は、WordPress Playground の素晴らしい入門です。ぜひお読みください。

深く掘り下げる​

開発者または技術系のユーザーであれば、利用可能な API を直接確認したいかもしれません。

  • Playground API と基本的な概念について読む
  • リンクとリソース を確認する
  • アプリに適した API を選択する
    • Query API enable basic operations using only query parameters
    • Blueprints API give you a great degree of control with a simple JSON file
    • JavaScript API give you full control via a JavaScript client from an npm package
  • アーキテクチャ を深く理解し、その仕組みを学ぶ

参加する​

WordPress Playground はオープンソースプロジェクトであり、コードからデザイン、ドキュメントからトリアージまで、すべての貢献者を歓迎します。ご心配なく、貢献するために WebAssembly の知識は必要ありません !

  • 貢献方法の詳細については、貢献者ハンドブック をご覧ください。
  • Slack の #playground チャンネルにご参加ください（サインアップ情報については、WordPress Slack ページ をご覧ください）。

すべての WordPress プロジェクトと同様に、私たちはすべての人にとって歓迎される環境を確保したいと考えています。そのため、すべての貢献者は私たちの 行動規範 に従うことが期待されます。
