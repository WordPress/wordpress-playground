લિંક્સ અને સંસાધનો

ટીપ

Playground સાથે સંબંધિત કેટલાક ટૂલ્સની ઍક્સેસને સરળ બનાવવા માટે રીડાયરેક્શન્સનો સેટ છે:

  • https://playground.wordpress.net/ → Playground ઇન્સ્ટન્સ
  • https://playground.wordpress.net/docs → Playground ડોક્સ
  • https://playground.wordpress.net/builder → Playground Blueprints Builder
  • https://playground.wordpress.net/wordpress → WordPress માટે Playground PR viewer
  • https://playground.wordpress.net/gutenberg → Gutenberg માટે Playground PR viewer
  • https://playground.wordpress.net/proxy → Playground Proxy Service (વધુ માહિતી માટે URLReference જુઓ)

WordPress Playground સાથે બનાવેલ એપ્લિકેશન્સ​

  • અધિકૃત demo અને showcase એપ – થીમ ઇન્સ્ટોલ કરો, પ્લગિન અજમાવો, કેટલાક પૃષ્ઠો બનાવો, તમે જે બનાવ્યું છે તે નિકાસ કરો
  • @wp-playground/cli – ત્વરિત WordPress dev environment માટે CLI ટૂલ
  • WordPress Playground for VS Code
  • Live Translations: App, announcement, more details
  • Interactive code block જે HTML Tag Processor tutorial અને Playground JS API tutorial ને સંચાલિત કરે છે
  • Gutenberg Pull Request previewer
  • Notifications plugin live demo
  • GraphQL REPL
  • Blocknotes – તમારા ફોન પર WordPress ચલાવતી પ્રથમ iOS એપ
  • Playground embedder shortcodes નો ઉપયોગ કરીને WordPress.org documentation માં Playground ઉદાહરણો એમ્બેડ કરવા માટે
  • Plugin demos on wp.org – એક user script જે WordPress.org પર plugin પૃષ્ઠો પર "demo" ટેબ ઉમેરે છે
  • WordPress Pull Request previewer
  • બે Playgrounds વચ્ચે સમન્વય
  • Time Travel
  • WP-CLI
  • Blueprints નું PHP implementation

વાંચન સામગ્રી​

  • WordPress Playground અને WebAssembly સાથે બ્રાઉઝરમાં WordPress અનુભવો બનાવો (અંગ્રેજીમાં)
  • developer.wordpress.org પર WordPress Playground (અંગ્રેજીમાં)
  • બ્રાઉઝરમાં WordPress ટેક ડેમો: WordPress Playground સાથે WordPress વિકાસ (અંગ્રેજીમાં)
  • make.wordpress.org પર પ્રારંભિક જાહેરાત (અંગ્રેજીમાં)
  • Hackernews ચર્ચા (અંગ્રેજીમાં)
